# RaiseTimeLine

X（Twitter）風の、テキスト中心のタイムライン形式の SNS アプリです。AIエンジニア養成コースの講義に沿って、学習目的で作っています。

## 特徴（予定）
- 投稿（280 文字まで。編集・削除）、画像投稿、コメント、いいね
- タイムライン：**全体**と**フォロー中**
- プロフィール（ユーザー名・アイコン画像・自己紹介）、フォロー・フォロワー、ユーザー名での検索
- **インプレッション数を表示しない。リツイート（再投稿）の機能がない。**（差別化）

## 状況
土台（ルール・スキル・設定）を作った段階です。要件定義は、これからです。

## 技術
バックエンド：Java + Spring Boot。画面：React（TypeScript）。DB：PostgreSQL。画像の保存先：AWS S3。詳しくは [docs/tech-stack.md](docs/tech-stack.md)。
