# RaiseTimeLine

**短い文章を投稿して、ほかの人と交流する、テキスト中心のタイムライン SNS アプリ。**
投稿・コメント・いいねの**数が分かり**、**自分の投稿にも、いいね・コメントができます**。作らないものを決めて、シンプルにしています。

AIエンジニア養成コースの課題として作る、3本目の個人開発アプリです（バックエンド：Java・Spring Boot、画面：React・TypeScript）。1本目（TaskManagement）、2本目（BizRequestTracker）は、使う人が1人でした。今回は、**複数のユーザーが使い、互いに関わる**アプリで、ユーザー登録・ログイン、フォロー、画像のクラウド保存（AWS S3）が、新しく出てきます。

## 特徴

### 作る機能
- **ユーザー登録とログイン**（別々の画面）。メールアドレス・パスワードでログインします（暫定）
- **投稿**：280 文字まで。自分の投稿は、**編集**（「編集済み」と表示）と**削除**ができます。画像も付けられます（保存先は AWS S3）
- **タイムライン**：**全体**と**フォロー中**の2種類。下へ進むと、自動で続きが読み込まれます
- **コメント**：投稿に、コメントと**返信**（1段）ができます。コメントの数（返信を含む）が分かります
- **いいね**：数が分かり、数を押すと、**いいねした人の一覧**が見られます
- **プロフィール・フォロー**：ユーザー名・アイコン・自己紹介、フォロー・フォロワーの数と一覧。投稿やコメントのユーザー名から、プロフィールへ移動して、フォローできます
- **ユーザー検索**：ユーザー名で、探せます

### 決めたこと（一部）
- **自分の投稿にも、いいね・コメントができます。** コメントへ誘導してインプレッションを増やす手口がある、という考えから、本人にも開いています。
- **インプレッション数は、表示しません。リツイート（再投稿）も、ありません。** シンプルに保つための、差別化です。
- **削除は、本当に消します**（投稿を消すと、コメント・いいね・画像も消える）。
- メールアドレスは、**他の人には見せません。**

## 使う技術（予定）

| 分野 | 技術 |
|---|---|
| バックエンド | Java、Spring Boot、Gradle |
| データベース | PostgreSQL（Docker） |
| 画面 | React、TypeScript、Vite、Material UI（部品集） |
| 画像の保存 | AWS S3 |
| インフラ（予定。変わるかもしれません） | AWS（EC2・RDS・ロードバランサー・S3）、Terraform |

1本目（TaskManagement）と、同じ技術・同じバージョンです。ただし、見た目の部品は、Tailwind CSS ではなく、**Material UI** にしました（講義にそろえた変更）。詳しくは [技術スタック](docs/tech-stack.md) に書いています。

## 作り方の特徴

- **要件定義は、二段構えで進めています。** 文書の構成は、1本目をひな形に、ドラフトを一気に作り、決めごとが多い所（編集・削除、コメントの返信、認証など）は、**選択肢を比べて、1つずつ決めました**。決めた日と理由は、文書に残しています。
- **決まっていないことを、隠しません。** 「未決」「暫定」「補足（AI の提案で、確認待ち）」を、文書の中で、はっきり区別しています。
- **すべての変更を、Issue → ブランチ → Pull Request の流れで、入れています。** 小さな修正も、例外なしです。`main` ブランチは、保護しています（直接の変更はできません）。
- **学んだことを、記録します。** [学習ノート](notes/README.md) に残していきます。
- **Claude Code（AI のコーディング支援）と、対話しながら進めています。** 作業は AI が進め、内容の確認と、機能・技術の決定は、私が行っています。
- **公開リポジトリとして、配慮しています。** サンプルデータは、すべて架空にします（メールアドレスは、実在しない形だけ）。パスワード・AWS の鍵などの秘密は、コミットしません。
