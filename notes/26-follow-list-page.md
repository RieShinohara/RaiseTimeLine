# フォロー中・フォロワーの一覧の画面

2026-11-21。Issue #151。プロフィールとフォロー（機能定義書 07）の画面の 3 つ目。API（ノート 23）をつないだ。これで、プロフィールとフォローの画面は、一通りそろった。

## 1. 作った物

| ファイル | 役割 |
|---|---|
| `api/users.ts` の `fetchFollowers`・`fetchFollowing` | サーバーへの注文（どちらの一覧か） |
| `profile/useFollowList.ts` | 一覧の読み込みと、行ごとのフォロー・解除を預かる係 |
| `pages/FollowListPage.tsx` | 画面（`kind` で、フォロワーとフォロー中を切り替える） |
| `pages/ProfilePage.tsx` | 数（フォロー中・フォロワー）を、押せるリンクにした |

- URL：`/users/:username/followers`・`/users/:username/following`。**同じ画面の部品を、`kind` という引数で切り替えて、2 つの URL に使う**（`<FollowListPage kind="followers" />`）。

## 2. 使い回したところ
- **行ごとのフォロー・解除**：ノート 13（いいね）の作り。送信中の人の集合＋`useRef` の印で連打を止め、結果を待ってから、その行だけを変える。
- **名前のリンク**：`AuthorName`（ノート 24）。投稿カード・コメント・一覧で、同じ部品。
- **自分の行にはボタンを出さない**：プロフィールの画面と同じ決まり。サーバーも、自分自身のフォローを 400 で断る（ノート 20）。

## 3. 設計の判断
- **ダイアログでなく、別の URL の画面にした**：戻るボタンが効く、リンクを人に送れる。ダイアログだと、閉じたらプロフィールに戻るだけで、一覧の URL は存在しない。
- **`key` に、種類と名前の両方を入れる**：`key={`${kind}:${username}`}`。「フォロワー」から「フォロー中」へ移るときも、別の人へ移るときも、前の一覧が残らない。
- **50 人まで**：サーバーが最初の 50 人だけ返す決まり（ノート 23）。超えるときは、「最初の 50 人を表示しています」と、正直に出す（黙って切ると、「これで全員」と誤解される）。
- **一覧でフォローしても、持ち主の数は変わらない**：持ち主（一覧の元のプロフィール）のフォロー数・フォロワー数は、そのプロフィールに戻ったとき読み直される。一覧の中で、無理に数を同期しない（`key` による作り直しが、これを自然に解決する）。

## 4. 気づき
- **④のテストが壊れた**：数を押せるリンクに変えたので、④のテストが「数の文字の親の要素」を探していた所が合わなくなった。「見た目の構造」ではなく、**ユーザーが見る形（リンクの名前『5 フォロー中』）**で探す形に直した。見た目の構造に頼ったテストは、構造を変えると壊れる。
- 画面の見出しの文字は、JSX の書き方（`@{username} の{TITLES[kind]}`）で、空白の入り方が決まる。テストの期待が 1 文字違って落ちた。画面の文字を見て、期待を直した。

## 5. わざと壊して、赤くなるか確かめた（1 回に 1 か所）
- 自分の行にも、ボタンを出す → 「自分の行には、ボタンが出ない」の 1 件だけが落ちた
- フォロワーとフォロー中の、読み先を取り違える → 14 件が落ちた（ほとんどのテストが、フォロワーの一覧を前提にしているため）。「フォロー中の一覧は、following の一覧を読む」が、取り違えを直接見張っている
- 戻すと、すべて成功（165 件）

## 6. 本物のブラウザで確かめたこと
本物のバックエンド・DB で、Chrome DevTools（MCP）を使って、架空のユーザー 3 人（X が持ち主。Y・Z が X をフォロー。X は Y をフォロー）で確かめた。
- ログインなしで、プロフィールの「2 フォロワー」を押す → 一覧（新しい順：Z → Y）が出る。行にフォローのボタンが出る
- Z としてログイン → 一覧の Z（自分）の行には、ボタンが出ない。Y の行だけに出る
- Y の「フォロー」を押す → その行のボタンが「フォロー解除」に変わる（通信は `PUT /api/users/…/follow` が 1 回、200）
- 行の名前を押す → Y のプロフィールへ移り、フォロワーが 2 人（X と Z）になっている
- 0 件の一覧は「まだいません」、存在しないユーザーは「ユーザーが見つかりません」
- コンソールの警告は 0 件
- 見た目（色・余白）は、ユーザーの確認が必要
