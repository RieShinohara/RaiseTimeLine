### 3. 良かった点
- **MyBatis の SQL は、すべて `#{}`**。`${}` は 0 件（`UserMapper`・`RefreshTokenMapper` を確認）
- **応答に、パスワード（ハッシュ）が入らない。** `UserResponse` に、項目がない。JWT の中身は、ID とメールだけ
- **ログイン失敗の文言が、1 つ**で、どちらが違うか分からない（テストもある）
- **署名の鍵が、リポジトリにない。** `application.yml` は `${JWT_SECRET}` で、テストだけ、ダミーの鍵を `build.gradle` で渡している。鍵が 32 文字未満だと、起動時に落ちる（jjwt の仕様）ので、弱い鍵で気づかず動くことはない
- 同じメール・同じユーザー名の**同時登録**にも、`DuplicateKeyException` で備えている（DB の一意索引が最後の砦）
- `actuator` は `health` だけを公開。`server.address` は `127.0.0.1`
- 画面：札の更新を**同時に 1 回だけ**にしている（`refreshing`）。通信の失敗と、札が無効なときを、区別している（通信の失敗では、ログアウトしない）。localStorage が使えなくても落ちない
- テストが、実際の DB（Testcontainers）で、登録 → ログイン → 更新 → ログアウトまで通している
