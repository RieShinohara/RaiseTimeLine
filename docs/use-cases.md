# ユースケース（一覧）

利用者が、目的を達成するまでの操作の流れ。**詳しい流れは、各機能定義書にある**（機能が多く、重いため、機能ごとに分けた）。
機能の一覧は [機能一覧](features.md) を参照。

> **状態：ドラフト（2026-11-13）。** 流れの細部は、未決の点が決まったら、見直す。
> 利用者は、「ログインしているユーザー」。ログインしていない人は、UC-1・UC-2 だけ（【未決】タイムラインを見られるか）。
