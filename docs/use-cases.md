# ユースケース

利用者が、目的を達成するまでの操作の流れを定める。
機能の一覧は [機能一覧](functional-requirements.md) を参照。

> **状態：ドラフト（2026-11-13）。** 流れの細部は、未決の点（【未決】）が決まったら、見直す。画面の詳細は、画面設計（これから）で定める。
> 利用者は、「ログインしているユーザー」。ログインしていない人は、UC-1・UC-2 だけ（【未決】タイムラインを見られるか）。

| ID | ユースケース |
|---|---|
| UC-1 | ユーザー登録する |
| UC-2 | ログイン・ログアウトする |
| UC-3 | 投稿する（画像つきを含む） |
| UC-4 | 自分の投稿を編集する |
| UC-5 | 自分の投稿を削除する |
| UC-6 | タイムライン（全体・フォロー中）を見る |
| UC-7 | 投稿にコメントする |
| UC-8 | 投稿にいいねする・取り消す |
| UC-9 | プロフィールを見る（ユーザー名から移動する） |
| UC-10 | ユーザーをフォローする・解除する |
| UC-11 | 自分のプロフィールを編集する |

## UC-1: ユーザー登録する
- 利用者：新しい利用者
- 目的：アカウントを作る
- 事前条件：ログインしていない
- 基本の流れ：
  1. 「ユーザー登録」の画面（ログインとは別の画面）を開く
  2. ユーザー名とパスワードを入力する（【未決】メールアドレス）
  3. 「登録」を押す
  4. アカウントが作られる（登録後に、ログインした状態にするか、ログイン画面へ進むかは【未決】）
- 例外の流れ：
  - ユーザー名が、すでに使われているときは、登録できず、理由を表示する
  - 入力が条件を満たさないとき（空、文字数、パスワードの強さ）は、登録できず、理由を表示する

## UC-2: ログイン・ログアウトする
- 目的：自分のアカウントで使い始める／終える
- 基本の流れ：
  1. 「ログイン」の画面で、ユーザー名とパスワードを入力して、「ログイン」を押す
  2. 成功したら、タイムラインの画面へ進む
  3. 使い終わったら、「ログアウト」を押す。ログインの画面へ戻る
- 例外の流れ：
  - ユーザー名かパスワードが違うときは、ログインできず、「ユーザー名かパスワードが違います」と表示する（どちらが違うかは、教えない。【補足】）

## UC-3: 投稿する（画像つきを含む）
- 事前条件：ログインしている
- 基本の流れ：
  1. 投稿の入力欄に、本文を入力する（残りの文字数が分かる）
  2. 必要なら、画像を選ぶ
  3. 「投稿」を押す
  4. 投稿が、タイムラインの一番上に表示される
- 例外の流れ：
  - 本文が空、または 281 文字以上のときは、投稿できない
  - 画像が、条件（種類、サイズ）を満たさないときは、投稿できず、理由を表示する（【未決】条件）

## UC-4: 自分の投稿を編集する
- 事前条件：自分の投稿である
- 基本の流れ：
  1. 自分の投稿の「編集」を押す
  2. 本文を直して、「保存」を押す（「キャンセル」で、直しを捨てる）
  3. 投稿の表示が、直した内容になる（【未決】「編集済み」の表示）
- 補足：他の人の投稿には、「編集」が表示されない。サーバー側でも、拒否する

## UC-5: 自分の投稿を削除する
- 事前条件：自分の投稿である
- 基本の流れ：
  1. 自分の投稿の「削除」を押す
  2. 確認メッセージが表示される
  3. 「削除する」を押す
  4. 投稿が、表示されなくなる（付いていたコメント・いいね・画像の扱いは【未決】）
- 例外の流れ：確認メッセージで「キャンセル」を押したら、削除されない

## UC-6: タイムラインを見る
- 基本の流れ：
  1. ログイン後の画面で、「全体」と「フォロー中」を、切り替えて選ぶ
  2. 選んだタイムラインの投稿が、新しい順に表示される
  3. 各投稿に、ユーザー名、本文、画像、投稿日時、いいねの数、コメントの数が表示される
- 補足：「フォロー中」は、誰もフォローしていないとき、案内を表示する（【補足】「まだ誰もフォローしていません」）。件数が多いときの見せ方は【未決】

## UC-7: 投稿にコメントする
- 事前条件：ログインしている（自分の投稿にも、できる）
- 基本の流れ：
  1. 投稿を開く（またはコメントの欄を開く）
  2. コメントの本文を入力して、「コメント」を押す
  3. コメントが、その投稿のコメント欄に表示され、コメントの数が増える
- 補足：コメントを書いたユーザー名から、プロフィールへ移動できる（UC-9）。返信、削除、編集は【未決】

## UC-8: 投稿にいいねする・取り消す
- 事前条件：ログインしている（自分の投稿にも、できる）
- 基本の流れ：
  1. 投稿の「いいね」を押す
  2. いいねの数が 1 増え、押した状態の表示になる
  3. もう一度押すと、取り消され、数が 1 減る

## UC-9: プロフィールを見る
- 基本の流れ：
  1. 投稿やコメントのユーザー名を押す（またはユーザー検索の結果から選ぶ）
  2. そのユーザーのプロフィールが表示される（ユーザー名、アイコン画像、自己紹介、フォロー数、フォロワー数、投稿の一覧）

## UC-10: ユーザーをフォローする・解除する
- 事前条件：ログインしている。他のユーザーのプロフィールを開いている
- 基本の流れ：
  1. 「フォロー」を押す
  2. ボタンが「フォロー解除」に変わり、相手のフォロワー数が 1 増える
  3. 「フォロー解除」を押すと、元に戻る
- 補足：自分のプロフィールには、「フォロー」を表示しない

## UC-11: 自分のプロフィールを編集する
- 基本の流れ：
  1. 自分のプロフィールの「編集」を押す
  2. アイコン画像、自己紹介を変更して、「保存」を押す（【未決】ユーザー名の変更）

## UC-12: ユーザーを検索する
- 基本の流れ：
  1. 検索の欄に、ユーザー名（の一部）を入力して、検索する
  2. 一致したユーザーの一覧が表示される
  3. ユーザーを選ぶと、プロフィールが開く（UC-9）
- 例外の流れ：一致するユーザーがいないときは、「見つかりません」と表示する
- 一致のしかた・件数は【未決】
