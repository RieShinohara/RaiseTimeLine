# 要件定義書：RaiseTimeLine（X 風のタイムライン SNS）

この文書は、要件定義の全体像をまとめたもの（入口）。詳細は、内容ごとに別のドキュメントに分けている。

> **状態：ドラフト（2026-11-13）。** 決まっていない点は「【未決】」、Claude Code が補った提案は「【補足】」と書いてある。これらは、1つずつ、ユーザーと決める。

## 1. 背景・目的
### 1.1 背景
- AI エンジニア養成コースの講義に沿って、学習目的で作る 3 本目のアプリ（1 本目：TaskManagement、2 本目：BizRequestTracker）
- これまでの 2 本は、利用者が 1 人だった。今回は、**複数のユーザーが使い、互いに関わる**アプリを作る（ユーザー登録、ログイン、他の人の投稿へのいいね・コメント、フォロー）
- 画像の保存先を、クラウド（AWS S3）にする

### 1.2 目的
- 短い文章（280 文字まで）を投稿して、ほかのユーザーと交流できる、テキスト中心のタイムライン SNS を作る
- 複数ユーザーが使うアプリに必要な、認証、データの持ち方、画像のクラウド保存、AWS への配置を、学ぶ
- **作らないものを決める**（インプレッション数の表示、リツイート）。シンプルな SNS にする

## 2. 利用者
- 受講生・個人。**複数のユーザー**が、それぞれのアカウントで使う
- 管理者の機能は、ない（【未決】要るか。ふつうは要らない）

## 4. 範囲の概要
- ユーザー登録（ログインとは別の画面）とログインができる
- 投稿（280 文字まで）、編集、削除ができる。画像を付けられる（保存先は AWS S3）
- タイムラインは 2 種類：**全体**と**フォロー中**
- 投稿に、**コメント**と**いいね**ができる。どちらも**数が分かる**。**投稿した本人も、自分の投稿にできる**
- プロフィール（ユーザー名、アイコン画像、自己紹介、フォロー・フォロワー）を見られる
- ユーザー名で、ユーザーを検索できる
- 投稿やコメントのユーザー名から、プロフィールへ移動し、フォローできる
- **作らない**：インプレッション数の表示、リツイート（再投稿）

機能の詳細は [機能一覧](functional-requirements.md) を参照。

## 5. 受け入れ条件（完成の基準）【ドラフト。未決の点が決まったら、見直す】
### 5.1 ユーザー
- ユーザー登録の画面で登録でき、ログインの画面で、登録したユーザーでログインできる
- ログインしていない人は、投稿・コメント・いいね・フォローができない（【未決】ログインなしで、タイムラインを見られるか）
- ログアウトできる

### 5.2 投稿
- 280 文字までの投稿ができる。281 文字以上は、投稿できない
- 自分の投稿を、編集・削除できる。他の人の投稿は、編集・削除できない
- 削除の前に、確認メッセージが表示される。削除すると、付いていたコメント・いいね・画像も消える
- 編集した投稿には、「編集済み」と表示される。編集できるのは本文だけ
- 投稿に、画像を付けられる。画像は、AWS S3 に保存される（【未決】枚数、サイズ、種類の制限）

### 5.3 タイムライン
- 「全体」のタイムラインに、全ユーザーの投稿が、新しい順で表示される
- 「フォロー中」のタイムラインに、フォローしているユーザーの投稿と、自分の投稿が、新しい順で表示される
- 投稿が多いときは、下へ進むと、自動で続きが読み込まれる

### 5.4 コメント・いいね
- 投稿に、コメントできる。コメントに、返信できる（1 段だけ）。投稿ごとに、コメントの数（返信を含む）が表示される
- コメント・返信は、書いた人と、その投稿をした人が、削除できる（編集は、できない）
- 投稿に、いいねできる。投稿ごとに、いいねの数が表示される。もう一度押すと、取り消せる（【補足】取り消し）
- いいねの数を押すと、いいねした人の一覧が見られる（コメントには、いいねできない）
- 自分の投稿にも、いいね・コメントができる

### 5.5 プロフィール・フォロー・検索
- プロフィールに、ユーザー名、アイコン画像、自己紹介、フォロー数、フォロワー数が表示される
- 自分のプロフィールを、編集できる
- 投稿やコメントのユーザー名を押すと、そのユーザーのプロフィールへ移動する
- プロフィールから、フォロー・フォロー解除ができる
- ユーザー名で、ユーザーを検索できる

### 5.6 その他
- ブラウザを閉じて開き直しても、投稿などのデータが消えない
- パスワードが、そのままの形で保存されていない（非機能要件）
- インプレッション数が、どこにも表示されない。リツイートの機能が、ない
