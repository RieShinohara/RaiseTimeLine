# 機能定義書 04：タイムライン（全体・フォロー中）

> **状態：ドラフト（2026-11-13）。** 「【未決】」は、まだ決まっていない点。「【補足】」は、Claude Code が補った提案（ユーザーの確認待ち）。
> 全体の機能は [機能一覧](../functional-requirements.md) を参照。

## 1. 概要と目的
- 投稿を、新しい順に並べて見る、メインの画面
- 2 種類ある：**全体**（全ユーザーの投稿）と、**フォロー中**（フォローしているユーザーの投稿）

## 2. 決まっていること
- 「全体」：全ユーザーの投稿を、新しい順に表示する
- 「フォロー中」：フォローしているユーザーの投稿を、新しい順に表示する
- 2 つを、切り替えて見られる
- 各投稿に、投稿者のユーザー名（アイコンつき）、本文、画像、投稿日時、いいね数、コメント数を表示する
- 投稿者のユーザー名を押すと、そのユーザーのプロフィールへ移動する（[07](07-profile-follow.md)）
- 誰もフォローしていないときの「フォロー中」には、案内を表示する（【補足】「まだ誰もフォローしていません」）。ただし、自分の投稿があれば、それは表示される
- **「フォロー中」には、自分の投稿も含める**（TL-1。2026-11-13 決定）
- **投稿が多いときは、下へ進むと、自動で続きを読み込む**（TL-2。2026-11-13 決定）。1 回に読み込む件数は、20 件（【補足】仮の値。実装・動作確認で調整する）
- 【補足】新しい投稿は、自動では更新しない。画面を開き直す、または「更新」を押すと、最新になる（TL-4。自分が投稿したときは、一番上にすぐ出る）

## 3. 操作の流れ（ユースケース）

### UC-6: タイムラインを見る
- 事前条件：ログインしている（【未決】ログインなしで見られるか）
- 基本の流れ：
  1. ログイン後の画面で、「全体」と「フォロー中」を、切り替えて選ぶ
  2. 選んだタイムラインの投稿が、新しい順に表示される
  3. 各投稿に、ユーザー名、本文、画像、投稿日時、いいねの数、コメントの数が表示される
  4. 投稿の入力欄から、新しい投稿ができる（[02](02-post.md)）
- 例外の流れ：
  - 投稿が 1 件もないときは、「まだ投稿がありません」と表示する（【補足】）
  - 読み込みに失敗したときは、「読み込めませんでした」と表示する（【補足】）

## 4. 画面に出るもの
- 「全体」「フォロー中」の切り替え
- 投稿の入力欄、投稿のカードの並び
- 一番下まで進んだときの、続きの読み込み中の表示、「これ以上ありません」の表示（【補足】）
- 最新にする「更新」の操作（【補足】）
- 詳細は、画面設計（これから）で定める

## 5. 使うデータ
- POST（新しい順は created_at）、FOLLOW（フォロー中の絞り込み）、集計としての POST_LIKE・COMMENT の件数。[データ設計](../data-design.md)
