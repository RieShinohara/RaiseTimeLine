# 機能定義書 03：画像（投稿の画像・アイコン画像。保存先は AWS S3）

> **状態：ドラフト（2026-11-13）。** 「【未決】」は、まだ決まっていない点。「【補足】」は、Claude Code が補った提案（ユーザーの確認待ち）。
> 全体の機能は [機能一覧](../functional-requirements.md) を参照。

## 1. 概要と目的
- 投稿に付ける画像と、プロフィールのアイコン画像を、扱う機能
- 画像の保存先は、**AWS S3**（クラウド。講義の内容）。データベースには、場所（キー）だけを保存する
- このアプリで初めて出てくる、クラウドの保存先（学習の新しい点）

## 2. 決まっていること
- 画像の本体は、S3 に置く。データベースには、場所（キー）だけを持つ
- 投稿に、画像を付けられる
- プロフィールに、アイコン画像を設定できる
- ファイルの種類とサイズは、**サーバー側で必ず確認する**（[非機能要件](../non-functional-requirements.md) 4）
- アイコン画像が未設定のときは、初期の画像（自分で作った簡単な図。【補足】）を表示する
- リポジトリに、ユーザーがアップロードした画像を入れない。テストの画像は、テストコードの中で作る（CLAUDE.md 4）

## 3. 操作の流れ
画像だけの独立したユースケースは作らない。次の流れの中で使う。
- 投稿に画像を付ける：[UC-3 投稿する](02-post.md)
- アイコン画像を変える：[UC-11 自分のプロフィールを編集する](07-profile-follow.md)

画像を選んだときの共通の動き：
1. 「画像を選ぶ」を押して、ファイルを選ぶ
2. 条件（種類、サイズ）を満たしていれば、プレビューが表示される
3. 投稿（または保存）を押したときに、画像が S3 に保存される
- 例外：種類やサイズが条件に合わないときは、選んだ時点で、理由を表示する（サーバー側でも、確認する）

## 4. 画面に出るもの
- 「画像を選ぶ」ボタン、選んだ画像のプレビュー、選びなおす・外すボタン
- 投稿・プロフィールでの、画像の表示
- 詳細は、画面設計（これから）で定める

## 5. 使うデータ
- POST.image_key、USER.icon_key（S3 上の場所）。[データ設計](../data-design.md)
- 実際のファイルは、S3 のバケットに置く（構成は、AWS の構成図で定める）

## 6. エラー・例外
- 種類・サイズの条件に合わない：保存できず、理由を表示する
- S3 への保存に失敗した：投稿・保存を完了させず、「画像を保存できませんでした」と表示する（【補足】）
- 保存した画像の表示に失敗した（S3 にない、など）：画像の代わりに、案内を表示する（【補足】）

## 7. 未決の点
| ID | 未決の点 |
|---|---|
| IMG-1 | S3 の画像を、誰でも見られるようにするか（公開）、アプリを通して見せるか（非公開。期限つきの URL など） |
| IMG-2 | 1 つの投稿に付けられる画像の枚数（1 枚か、複数か） |
| IMG-3 | 画像のサイズの上限（目安：5MB）と、種類（JPEG・PNG など）。縮小して保存するか |
| IMG-4 | アップロードの方式（ブラウザから S3 へ直接か、バックエンドを通すか） |
| IMG-5 | 画像を差し替えた・投稿を消したときの、S3 の古い画像の扱い（消すか） |
