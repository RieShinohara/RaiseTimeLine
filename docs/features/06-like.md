# 機能定義書 06：いいね

> **状態：ドラフト（2026-11-13）。** 「【未決】」は、まだ決まっていない点。「【補足】」は、Claude Code が補った提案（ユーザーの確認待ち）。
> 全体の機能は [機能一覧](../features.md) を参照。

## 1. 概要と目的
- 投稿に「いいね」と、軽く反応する機能
- **いいねの数が分かる**（講義の内容）
- **投稿した本人も、自分の投稿に、いいねできる**（ユーザー決定、2026-11-12）

## 2. 決まっていること
- ログインしているユーザーは、どの投稿にも、いいねできる（自分の投稿にも）
- 投稿ごとに、いいねの数を表示する
- 【補足】同じ投稿に、同じユーザーは、1 回だけ。もう一度押すと、取り消せる
- 【補足】自分が、いいねした投稿は、押した状態の見た目で分かる
- **いいねは、投稿に対してだけ**。コメントには、いいねできない（LIKE-1。2026-11-13 決定）
- **「誰がいいねしたか」の一覧を、見られる**。いいねの数を押すと、いいねした人の一覧が開き、そこから、プロフィールへ移動できる（LIKE-2。2026-11-13 決定）

## 3. 操作の流れ（ユースケース）

### UC-8: 投稿にいいねする・取り消す
- 事前条件：ログインしている（自分の投稿にも、できる）
- 基本の流れ：
  1. 投稿の「いいね」を押す
  2. いいねの数が 1 増え、押した状態の表示になる
  3. もう一度押すと、取り消され、数が 1 減る
- 例外の流れ：
  - 通信に失敗したときは、数と見た目を元に戻し、「うまくいきませんでした」と表示する（【補足】）
  - 同時に、同じ人が連続で押しても、1 回分しか数えない（二重のいいねを作らない）

### UC-15: いいねした人の一覧を見る
- 事前条件：ログインしている
- 基本の流れ：
  1. 投稿の「いいねの数」を押す
  2. いいねした人の一覧が表示される（ユーザー名、アイコン。新しい順。【補足】）
  3. ユーザーを選ぶと、プロフィールが開く（UC-9）
- 例外の流れ：いいねが 0 件のときは、数を押しても何も開かない、または「まだいいねがありません」と表示する（【補足】）
- 補足：自分の投稿でも、他の人の投稿でも、同じように見られる

## 4. 画面に出るもの
- 投稿のカードの、いいねボタンと、いいねの数（押すと、いいねした人の一覧）
- いいねした人の一覧（窓、または画面）
- 詳細は、画面設計（これから）で定める

## 5. 使うデータ
- POST_LIKE（投稿、ユーザー。同じ組み合わせは 1 つだけ）。いいね数は、POST_LIKE の件数。[データ設計](../database-design.md) 2.4

## 6. エラー・例外
- 削除された投稿に、いいねしようとした：「投稿が見つかりません」と表示する（【補足】）
- ログインしていない：ログインの画面へ案内する
