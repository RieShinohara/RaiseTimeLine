# 機能定義書 07：プロフィール・フォロー

> **状態：ドラフト（2026-11-13）。** 「【未決】」は、まだ決まっていない点。「【補足】」は、Claude Code が補った提案（ユーザーの確認待ち）。
> 全体の機能は [機能一覧](../functional-requirements.md) を参照。画像は [03 画像](03-image.md)。

## 1. 概要と目的
- ユーザーを紹介する場所（プロフィール）と、気になるユーザーの投稿を追う仕組み（フォロー）
- 投稿やコメントのユーザー名から、プロフィールへ移動し、そこからフォローできる

## 2. 決まっていること
- プロフィールに、ユーザー名、アイコン画像、自己紹介、フォロー数、フォロワー数、そのユーザーの投稿の一覧を表示する
- 自分のプロフィールは、編集できる（アイコン画像、自己紹介）
- フォロー・フォロー解除は、他のユーザーのプロフィールから行う
- 自分自身は、フォローできない（【補足】）
- 投稿・コメントのユーザー名を押すと、そのユーザーのプロフィールへ移動する
- フォローしているユーザーの投稿は、「フォロー中」のタイムラインに出る（[04](04-timeline.md)）
- フォロー中・フォロワーの一覧を見られる（【補足】講義では「数」。一覧は、不明）

## 3. 操作の流れ（ユースケース）

### UC-9: プロフィールを見る
- 基本の流れ：
  1. 投稿やコメントのユーザー名を押す（またはユーザー検索の結果から選ぶ）
  2. そのユーザーのプロフィールが表示される（ユーザー名、アイコン画像、自己紹介、フォロー数、フォロワー数、投稿の一覧）
- 例外の流れ：存在しないユーザーのときは、「ユーザーが見つかりません」と表示する（【補足】）

### UC-10: ユーザーをフォローする・解除する
- 事前条件：ログインしている。他のユーザーのプロフィールを開いている
- 基本の流れ：
  1. 「フォロー」を押す
  2. ボタンが「フォロー解除」に変わり、相手のフォロワー数が 1 増える
  3. 「フォロー解除」を押すと、元に戻る
- 補足：自分のプロフィールには、「フォロー」を表示しない

### UC-11: 自分のプロフィールを編集する
- 事前条件：ログインしている。自分のプロフィールを開いている
- 基本の流れ：
  1. 自分のプロフィールの「編集」を押す
  2. アイコン画像、自己紹介を変更して、「保存」を押す（【未決】ユーザー名の変更）
- 例外の流れ：自己紹介が文字数の上限を超えるとき、画像が条件に合わないときは、保存できず、理由を表示する

## 4. 画面に出るもの
- プロフィールの画面（ユーザー名、アイコン、自己紹介、フォロー数・フォロワー数、フォロー／フォロー解除ボタン、投稿の一覧）
- プロフィールの編集の画面（または窓）
- フォロー中・フォロワーの一覧（【補足】）
- 詳細は、画面設計（これから）で定める

## 5. 使うデータ
- USER（ユーザー名、アイコン、自己紹介）、FOLLOW（フォローする側・される側）、POST。[データ設計](../data-design.md) 2.1、2.5

## 6. エラー・例外
- 自分自身をフォローしようとした（画面を通さない直接の要求）：サーバーが拒否する
- すでにフォローしている相手を、もう一度フォローした：二重に作らない（エラーにせず、そのまま）（【補足】）
- 他の人のプロフィールを、編集しようとした：サーバーが拒否する

## 7. 未決の点
| ID | 未決の点 |
|---|---|
| PF-1 | ユーザー名を、あとから変えられるか |
| PF-2 | 自己紹介の文字数の上限 |
| PF-3 | フォロー中・フォロワーの一覧の画面を作るか（数だけにするか） |
| PF-4 | プロフィールの投稿の一覧の並び・件数（タイムラインと同じ見せ方でよいか） |
| PF-5 | 他のユーザーのプロフィールを、ログインしていない人が見られるか |
