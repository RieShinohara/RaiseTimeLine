# 機能定義書 05：コメント（返信を含む）

> **状態：ドラフト（2026-11-13。主な未決は決定済み）。** 「【補足】」は、Claude Code が補った提案（ユーザーの確認待ち）。
> 全体の機能は [機能一覧](../features.md) を参照。

## 1. 概要と目的
- 投稿に、一言の感想や返事を付ける機能。コメントには、**返信**もできる
- **コメントの数が分かる**（いいねと同様。ユーザー決定、2026-11-12）
- **投稿した本人も、自分の投稿に、コメントできる**（ユーザー決定、2026-11-12。コメントへの誘導でインプレッションを増やす手口がある、という考えから。このアプリは、インプレッション数を表示しない）

## 2. 決まっていること
- ログインしているユーザーは、どの投稿にも、コメントできる（自分の投稿にも）
- **コメントへの返信を作る。返信は、1 段だけ**（「投稿 → コメント → 返信」まで。返信への返信は、同じコメントの返信として並べる）（CMT-1・CMT-1a。2026-11-13 決定）
- **コメントの数には、返信を含める**（投稿に付いた、コメントと返信の合計）（CMT-1b。2026-11-13 決定）
- **削除できるのは、書いた人と、その投稿をした人**（自分の投稿に付いたコメント・返信を、消せる）（CMT-3。2026-11-13 決定）
- **返信が付いているコメントを削除すると、返信も一緒に、本当に消える**。確認メッセージに、そのことを書く（CMT-1c。2026-11-13 決定）
- **コメント・返信は、編集できない**（直したいときは、削除して、書き直す）（CMT-4。2026-11-13 決定）
- **コメントは、投稿の詳細画面で、見て、書く**（投稿を押すと、その投稿と、コメント・返信が並ぶ画面へ移動する）（CMT-6。2026-11-13 決定）
- **並び順は、古い順**。返信は、各コメントの下に、古い順（CMT-5。2026-11-13 決定）
- 【補足】文字数の上限は、投稿と同じ 280 文字まで（CMT-2。空のコメントはできない）
- コメントには、書いたユーザーの名前（アイコンつき）、本文、日時を表示する。ユーザー名を押すと、プロフィールへ移動する（[07](07-profile-follow.md)）
- コメントの数は、投稿のカードにも表示する

## 3. 操作の流れ（ユースケース）

### UC-7: 投稿にコメントする
- 事前条件：ログインしている（自分の投稿にも、できる）
- 基本の流れ：
  1. 投稿を押して、投稿の詳細画面を開く
  2. コメントの本文を入力して、「コメント」を押す
  3. コメントが、その投稿のコメント欄の末尾（古い順）に表示され、コメントの数が増える
- 例外の流れ：
  - 本文が空、または 281 文字以上のときは、コメントできない
- 補足：コメントを書いたユーザー名から、プロフィールへ移動できる（UC-9）

### UC-13: コメントに返信する
- 事前条件：ログインしている。投稿の詳細画面を開いている
- 基本の流れ：
  1. コメントの「返信」を押す
  2. 返信の本文を入力して、「返信」を押す
  3. 返信が、そのコメントの下の、末尾（古い順）に表示され、コメントの数（返信を含む合計）が増える
- 補足：返信への「返信」を押したときも、同じコメントの返信として並ぶ（1 段のまま）。誰に返したかが分かるよう、返信の先頭に、相手のユーザー名を付けるか否かは、画面設計で決める（【補足】）
- 例外の流れ：本文が空・281 文字以上のときは、返信できない

### UC-14: コメント・返信を削除する
- 事前条件：書いた人、または、その投稿をした人
- 基本の流れ：
  1. コメント（または返信）の「削除」を押す
  2. 確認メッセージが表示される（返信の付いたコメントでは、「返信も消えます」と書く。元に戻せない）
  3. 「削除する」を押す
  4. コメント（と、その返信）が消え、コメントの数が減る
- 例外の流れ：確認メッセージで「キャンセル」を押したら、削除されない
- 補足：他の人のコメントを、投稿した人でもない人が消すことはできない（サーバー側でも、拒否する）

## 4. 画面に出るもの
- 投稿のカードの、コメント数
- **投稿の詳細画面**：投稿、コメントの入力欄、コメントの一覧（古い順。各コメントの下に返信）、各コメントの「返信」「削除」
- 詳細は、画面設計（これから）で定める

## 5. 使うデータ
- COMMENT（投稿、書いたユーザー、本文、日時、返信先のコメント）。コメント数は、その投稿の COMMENT の件数（返信を含む）。[データ設計](../database-design.md) 2.3

## 6. エラー・例外
- 本文が空・長すぎる：投稿できず、理由を表示する
- 削除された投稿・コメントに、コメント・返信しようとした：「見つかりません」と表示する（【補足】）
- 返信の返信を、画面を通さずに直接要求した：サーバーが拒否するか、1 段に直す（実装で決める）
