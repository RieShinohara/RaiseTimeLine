# 機能定義書 05：コメント

> **状態：ドラフト（2026-11-13）。** 「【未決】」は、まだ決まっていない点。「【補足】」は、Claude Code が補った提案（ユーザーの確認待ち）。
> 全体の機能は [機能一覧](../functional-requirements.md) を参照。

## 1. 概要と目的
- 投稿に、一言の感想や返事を付ける機能
- **コメントの数が分かる**（いいねと同様。ユーザー決定、2026-11-12）
- **投稿した本人も、自分の投稿に、コメントできる**（ユーザー決定、2026-11-12。コメントへの誘導でインプレッションを増やす手口がある、という考えから。このアプリは、インプレッション数を表示しない）

## 2. 決まっていること
- ログインしているユーザーは、どの投稿にも、コメントできる（自分の投稿にも）
- 投稿ごとに、コメントの数を表示する
- コメントには、書いたユーザーの名前（アイコンつき）、本文、日時を表示する。ユーザー名を押すと、プロフィールへ移動する（[07](07-profile-follow.md)）
- コメントの数は、投稿のカードにも表示する

## 3. 操作の流れ（ユースケース）

### UC-7: 投稿にコメントする
- 事前条件：ログインしている（自分の投稿にも、できる）
- 基本の流れ：
  1. 投稿を開く（またはコメントの欄を開く）
  2. コメントの本文を入力して、「コメント」を押す
  3. コメントが、その投稿のコメント欄に表示され、コメントの数が増える
- 例外の流れ：
  - 本文が空、または文字数の上限を超えるときは、コメントできない（上限は【未決】）
- 補足：コメントを書いたユーザー名から、プロフィールへ移動できる（UC-9）

## 4. 画面に出るもの
- 投稿のカードの、コメント数と、コメントを開くボタン
- コメントの一覧（書いた人、本文、日時）と、入力欄
- 詳細は、画面設計（これから）で定める

## 5. 使うデータ
- COMMENT（投稿、書いたユーザー、本文、日時）。コメント数は、COMMENT の件数。[データ設計](../data-design.md) 2.3

## 6. エラー・例外
- 本文が空・長すぎる：投稿できず、理由を表示する
- 削除された投稿に、コメントしようとした：「投稿が見つかりません」と表示する（【補足】）
