# 機能定義書 08：ユーザー検索

> **状態：ドラフト（2026-11-13）。** 「【未決】」は、まだ決まっていない点。「【補足】」は、Claude Code が補った提案（ユーザーの確認待ち）。
> 全体の機能は [機能一覧](../functional-requirements.md) を参照。

## 1. 概要と目的
- フォローしたいユーザーを、**ユーザー名**で探す機能（講義の内容）
- 投稿の本文の検索は、作らない（将来の候補。[機能一覧](../functional-requirements.md)）

## 2. 決まっていること
- 検索の対象は、ユーザー名
- **一致のしかたは、部分一致**（名前のどこかに、入力した文字があればよい）。**大文字小文字は区別しない**（SRCH-1。2026-11-13 決定）
- **検索の入力欄は、全画面のヘッダーに置く**（どの画面からでも、すぐ検索できる）。結果は、検索結果の画面に表示する（SRCH-3。2026-11-13 決定）
- 【補足】結果の並び順は、ユーザー名の順。表示は、20 件まで（SRCH-2。多いときは、条件をしぼってもらう案内を出す）
- 結果から、ユーザーを選ぶと、そのユーザーのプロフィールへ移動する（[07](07-profile-follow.md)）
- 一致するユーザーがいないときは、「見つかりません」と表示する（【補足】）

## 3. 操作の流れ（ユースケース）

### UC-12: ユーザーを検索する
- 事前条件：ログインしている
- 基本の流れ：
  1. 検索の欄に、ユーザー名（の一部）を入力して、検索する
  2. 一致したユーザーの一覧が表示される（ユーザー名、アイコン、自己紹介の一部。【補足】）
  3. ユーザーを選ぶと、プロフィールが開く（UC-9）
- 例外の流れ：
  - 一致するユーザーがいないときは、「見つかりません」と表示する
  - 入力が空のまま検索したときは、検索しない（【補足】）

## 4. 画面に出るもの
- 検索の欄（ヘッダーなど）、検索の結果の一覧
- 詳細は、画面設計（これから）で定める

## 5. 使うデータ
