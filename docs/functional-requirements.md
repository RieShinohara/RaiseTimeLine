# 機能一覧

RaiseTimeLine の機能を、「最初に作る」「将来追加する」「対象外」に分けて整理する。
各機能の操作の流れは [ユースケース](use-cases.md) を参照。

> **状態：ドラフト（2026-11-13）。** 「【未決】」は、まだ決まっていない点。「【補足】」は、Claude Code が補った提案（ユーザーの確認待ち）。

## 1. 最初に作る機能

### 1.1 ユーザー登録・ログイン
- ユーザー登録：**ログインとは別の画面**で行う
  - 入力：ユーザー名、パスワード（【未決】メールアドレスを使うか。ログインに使う ID は何か）
  - ユーザー名は、重複できない（【補足】他の人と同じ名前では登録できない。ユーザー名は検索に使うため）
- ログイン、ログアウト
- 認証の方式：【未決】（セッション方式か、トークン方式か。講義に合わせて決める）
- パスワードは、そのままの形では保存しない（非機能要件）

### 1.2 投稿
- 投稿の本文は、**280 文字まで**（空の投稿はできない）
- 投稿に、**画像**を付けられる（保存先は AWS S3。【未決】枚数、サイズ、種類の制限）
- **編集**：自分の投稿だけ。【未決】編集した投稿に「編集済み」と表示するか
- **削除**：自分の投稿だけ。削除の前に、確認メッセージを表示する。【未決】削除した投稿に付いていたコメント・いいね・画像の扱い（一緒に消す、など）
- 投稿の表示：投稿者のユーザー名（アイコン画像つき）、本文、画像、投稿日時、いいねの数、コメントの数

### 1.3 タイムライン
- **全体**：全ユーザーの投稿を、新しい順に表示する
- **フォロー中**：フォローしているユーザーの投稿を、新しい順に表示する。【未決】自分の投稿を含めるか
- 2 つを、切り替えて見られる
- 【未決】件数が多いとき（ページを分けるか、「もっと見る」か）
- 【未決】ログインしていない人が、見られるか

### 1.4 コメント
- 投稿に、コメントできる。コメントの本文の文字数：【未決】（投稿と同じ 280 文字までか）
- 投稿ごとに、**コメントの数が分かる**
- **投稿した本人も、自分の投稿に、コメントできる**
- コメントの削除：【未決】できるか（自分のコメントだけ？ 投稿者が、自分の投稿のコメントを消せるか？）
- コメントの編集：【未決】
- コメントへの返信（コメントへのコメント）：【未決】作るか。作る場合、コメント数に返信を含めるか
- コメントを書いたユーザーの名前から、プロフィールへ移動できる

### 1.5 いいね
- 投稿に、いいねできる。押すたびに、数が変わる
- 投稿ごとに、**いいねの数が分かる**
- **投稿した本人も、自分の投稿に、いいねできる**
- 【補足】同じ投稿に、同じユーザーは、1 回だけ。もう一度押すと、取り消せる
- 【未決】コメントにも、いいねできるか（講義では、投稿へのいいね。コメントへは、不明）
- 【未決】「誰がいいねしたか」を、見られるか

### 1.6 プロフィール・フォロー
- プロフィール：ユーザー名、アイコン画像（保存先は AWS S3）、自己紹介、フォロー数、フォロワー数、そのユーザーの投稿の一覧
- 自分のプロフィールを、編集できる（アイコン画像、自己紹介。【未決】ユーザー名を変えられるか）
- フォロー・フォロー解除：他のユーザーのプロフィールから行う。自分自身は、フォローできない（【補足】）
- フォロー中・フォロワーの一覧を見られる（【補足】一覧の画面。講義では「数」。一覧は、不明）
- 投稿やコメントの**ユーザー名**を押すと、そのユーザーのプロフィールへ移動する。そこから、フォローできる

### 1.7 ユーザー検索
- **ユーザー名**で、ユーザーを検索できる
- 【未決】一致のしかた（前方一致か、部分一致か）。結果の並び順、件数

## 2. 将来追加する機能（ドラフトの候補。【補足】）

- パスワードの再設定

## 3. 対象外（作らないもの）

- 管理者の機能（【未決】要るか）
- ダイレクトメッセージ（個別のやり取り）
- 動画の投稿
